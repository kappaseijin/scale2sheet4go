# decisions/

計画書（`PLAN.md` 等）を新規作成・大幅改訂する際に作成する検討書を格納する。手順は [PLAN.md「検討書ワークフロー」](../PLAN.md#検討書ワークフロー2026-07-04-導入恒久ルール) を参照。

## ファイル名規則

```text
yyyy-mm-ddThhMMSS_{何についての検討書か}.md
```

例: `2026-07-04T180000_計画書構成についての検討書.md`

## 記載内容

各検討書には最低限、次の3点を記載する。

- **採用した案** — 実際に採用した方針とその内容
- **却下した案** — 検討したが採用しなかった他の選択肢（複数可）
- **却下した理由** — それぞれの却下案について、採用しなかった理由

## テンプレート

```markdown
---
type: Decision
title: {テーマ}についての検討書
timestamp: "{yyyy-mm-ddThh:mm:ss+09:00}"
---

# {テーマ}についての検討書

## 背景

（何を決める必要があったか）

## 採用した案

（採用した案の内容と、採用した理由）

## 却下した案

### 案A: {案名}

却下した理由: ...

### 案B: {案名}

却下した理由: ...
```
