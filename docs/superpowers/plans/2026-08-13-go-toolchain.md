# Go 正本ツールチェーン整理実装計画

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Go Modules と Go CLI を scale2sheet の依存管理・build・test の唯一の正本にし、Node/npm/Bun を製品の既定経路から除去する。

**Architecture:** `go.mod` / `go.sum` と `go build` / `go test` / `go vet` / `gofmt` を直接利用する。現行の shell/Python acceptance は Go バイナリを呼び出す既存境界を維持し、Node の source fallback だけを削除する。旧 TypeScript 資産は比較履歴として残す。

**Tech Stack:** Go 1.22 module、Go standard CLI、既存 shell/Python acceptance。Node/npm/Bun/Makefile は現行の正本経路に追加しない。

**Spec:** `docs/decisions/2026-08-13T143340_Go正本ツールチェーンとpackage.jsonの扱いについての検討書.md`

## Global Constraints

- 1 Issue = 1 課題 = 1 PR とし、`Closes #4` は Issue #4 の完了条件を全て満たす場合だけ付ける。
- `go.mod` / `go.sum` を依存管理と checksum の正本にする。
- README は Node/npm/Bun を要求せず、Go CLI の直接コマンドだけで開発・build・test を再現できるようにする。
- 旧 `src/`、`test/`、`tsconfig.json`、`vitest.config.ts` はこの Issue では削除しない。
- Go の toolchain version policy と GitHub Actions の品質ゲートは Issue #5、macOS 本番環境は Issue #6 で扱う。
- 対向 LLM エージェントを配置せず、`scale2sheet_owner_codex` が自己検証する。
